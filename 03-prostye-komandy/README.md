# ДЗ №3 — Простые команды Bash: файлы и текст

> Дисциплина: **Операционные системы и среды**

## 📌 Суть задания

Освоить базовые команды для работы с каталогами, файлами и текстом в терминале Linux.

## 🛠 Что было сделано

**Часть 1 — создание файлов**
```bash
mkdir ~/work && cd ~/work && pwd     # создать каталог work, перейти в него, проверить путь
touch file.txt                       # создать пустой файл
echo "..." >> file.txt               # записать в файл текст (два абзаца)
cat file.txt                         # проверить содержимое
```

**Часть 2 — работа с текстом**
```bash
mv file.txt book.txt                 # переименовать файл
cat book.txt                         # проверка
grep "was" book.txt > was.txt        # строки со словом "was" — в отдельный файл
cat was.txt book.txt > total.txt     # склеить два файла в один
grep -o "n" total.txt | wc -l        # посчитать количество букв "n"
```

## 🎓 Что изучили

- Создание каталогов и файлов: `mkdir`, `touch`, `echo`.
- Навигация и просмотр: `cd`, `pwd`, `cat`.
- Переименование файлов через `mv`.
- Перенаправление вывода `>` / `>>` и объединение файлов через `cat`.
- Поиск по тексту `grep` (в т.ч. `-o` — каждое совпадение отдельной строкой) и подсчёт строк `wc -l`.
