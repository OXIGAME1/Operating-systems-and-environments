# ДЗ №1 — Создание снимков виртуальной машины

> Дисциплина: **Операционные системы и среды**

## 📌 Суть задания

Установить Debian в VirtualBox (или импортировать готовую ВМ), сделать **снимок (snapshot)** рабочей системы, а затем намеренно её «сломать» и восстановить из снимка.

## 🛠 Что было сделано

1. Установлен Debian в VirtualBox.
2. В меню **Инструменты → Снимки** создан снимок рабочего состояния ВМ.
3. Под суперпользователем `root` выполнен «патч Бармина» — команда, удаляющая всю файловую систему:
   ```bash
   rm -rf --no-preserve-root / 2>/dev/null
   ```
4. После принудительного выключения и перезапуска ВМ выдала **Kernel panic** — система уничтожена.
5. В меню снимков выбрано сохранённое состояние → **Восстановить** → ВМ снова загрузилась, как будто ничего не было.

## 🎓 Что изучили

- Что такое **снимок ВМ** и зачем он нужен: это сохранённое состояние всей системы, к которому можно откатиться в любой момент.
- При установке Debian создаются два пользователя — `root` и обычный; суперпользователь может делать с системой **всё**, в том числе полностью её уничтожить.
- Главный вывод: перед любыми экспериментами нужно делать снимок — это страховка от необратимых ошибок.
