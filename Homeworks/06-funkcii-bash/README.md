# ДЗ №6 — Функции в Bash

> Дисциплина: **Операционные системы и среды**

## 📌 Суть задания

Научиться объявлять функции в Bash, передавать им аргументы, использовать локальные переменные, `return` и `eval`.

## ❓ Вопрос: чем отличаются `exit` и `return`?

- **`return`** завершает только функцию и возвращает управление туда, откуда её вызвали, — скрипт продолжает работу.
- **`exit`** завершает весь скрипт (или текущую оболочку) целиком — всё, что после него, уже не выполнится.


## 🎓 Что изучили

- Синтаксис функций Bash: `имя() { ... }` и доступ к аргументам через `$1`, `$2`, …
- Локальные переменные `local` и коды возврата `return`.
- Перенаправление в поток ошибок `>&2` и дозапись в файл `>>`.
- Конструкцию `case` для разбора параметров.
- Команду `eval` и косвенное обращение к переменным, чтение ввода в цикле `while read` до EOF.
- Чем функции Bash отличаются от функций в «обычных» языках вроде Python.
