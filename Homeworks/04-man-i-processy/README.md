# ДЗ №4 — Администрирование: процессы и справочная система `man`

> Дисциплина: **Операционные системы и среды**

## 📌 Суть задания

Научиться смотреть запущенные процессы через `ps` и находить нужную информацию в справочной системе Linux (`man`, `apropos`).

## 🛠 Что было сделано

### Часть 1. Процессы

| Задача | Команда |
|---|---|
| Показать процессы деревом (родители → потомки) | `ps axf` |
| Найти процессы, запущенные **не** от root | `ps -U root -u root -N` |
| Топ-5 процессов по потреблению памяти | `ps aux --sort=-%mem \| head -n 6` |
| Процессы, работающие в фоне | `ps x` |

### Часть 2. Справочная система

| Задача | Команда |
|---|---|
| Найти в `man cp` ключ, сохраняющий владельца, права и время | `man cp \| grep -E "\-p\|preserve"` → ключ **`-p`** |
| Найти в `man man` поиск по ключевым словам | `man man \| grep -E "\-k\|keyword"` → ключ **`-k`** |
| Аналог `man -k`: найти все справки по слову *copy* | `apropos copy` |

## 🎓 Что изучили

- Как читать справку `man` и быстро фильтровать её через конвейер `|` и `grep`, не листая страницы вручную.
- `cp -p` копирует файл с сохранением прав, владельца и временных меток.
- `man -k` и `apropos` — одно и то же: поиск команд по ключевому слову (так нашлись `cp`, `cpio`, `dd`, `install`, `scp`).
- Как через `ps` с разными ключами смотреть дерево процессов, фильтровать их по пользователю и сортировать по памяти.
