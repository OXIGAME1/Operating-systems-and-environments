# ДЗ №5 — Администрирование 2: сеть, `ip` и `ping`

> Дисциплина: **Операционные системы и среды**

## 📌 Суть задания

Настроить сеть между гостевой ВМ (Ubuntu Server в VirtualBox) и хост-машиной: добавить адаптер *Host-Only*, вручную назначить ему IP-адрес и проверить связь в обе стороны.

## 🛠 Что было сделано

1. В настройках VirtualBox к ВМ подключён третий адаптер — **Host-Only Ethernet Adapter**.
2. Через `ip link` / `ip address` изучены сетевые интерфейсы: loopback (`lo`), NAT-адаптер для выхода в интернет и новый Host-Only адаптер.
3. На третьем адаптере вручную назначен свободный адрес из подсети `192.168.56.0/24`:
   ```bash
   ip address add 192.168.56.X/24 dev <интерфейс>
   ip link set <интерфейс> up
   ```
4. Проверена связь **гость → хост**:
   ```bash
   ping -c 10 192.168.56.1
   ```
5. Проверена связь **хост → гость** из командной строки Windows (`Win + R → cmd → ping 192.168.56.X`). Заодно выяснилось, что включённый VPN мешает пингу.

## 🎓 Что изучили

- Устройство команды `ip` и её объектов: `address`, `link`, `route`.
- Как читать вывод `ip address`: номер и имя интерфейса, MAC-адрес (`link/ether`), IPv4/IPv6-адреса (`inet` / `inet6`), состояние UP/DOWN.
- Разницу между адаптерами VirtualBox: loopback, NAT и Host-Only.
- Как работает `ping` (протокол ICMP) и почему без `-c N` в Linux он шлёт пакеты бесконечно.
- Важный урок: выполнять инструкцию по шагам и не торопиться 🙂
