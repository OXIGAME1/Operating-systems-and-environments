# ДЗ №7 — Автоматизация сборки: Unix Makefiles

> Дисциплина: **Операционные системы и среды**

## 📌 Суть задания

Автоматизировать сборку программы на ассемблере GASM с помощью утилиты `make`: вместо ручного вызова ассемблера и компоновщика собирать всё одной командой.

## 🛠 Что было сделано

1. Проверено, что установлены `make` и `binutils`: `make --version`, `as --version`.
2. Создан исходник `main.s` на GASM.
3. Сначала сборка выполнена вручную:
   ```bash
   as -o main.o main.s   # ассемблирование
   ld -o main main.o     # компоновка
   ```
4. Затем написан [`Makefile`](./Makefile), и сборка запускается одной командой:
   ```bash
   make build
   ```

Схема зависимостей: `main.s` → (`as`) → `main.o` → (`ld`) → `main`

## 🎓 Что изучили

- Из чего состоит Makefile: **цели**, **зависимости** и **команды**.
- `make` сам отслеживает, какой файл изменился, и пересобирает только нужное.
- Зачем нужна директива **`.PHONY`**: она помечает абстрактные цели (`clean`, `build`), не связанные с реальными файлами.
- `make clean` удаляет промежуточные объектные файлы, а `make build` собирает программу и сразу прибирает за собой.
